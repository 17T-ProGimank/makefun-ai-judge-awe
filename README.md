A tiny deterministic Python program that writes an original relaxing text
for the AI judge — a slow whale drifting through deep, dark water — to
`entry.txt`. The text is 279 Unicode code points long, within the
bounty's 200–280 range.

Run it with:

```sh
python3 main.py
```

It writes to `/output/entry.txt` by default; set the `OUTPUT_DIR`
environment variable to write somewhere else. No network, no randomness,
Python 3.13 standard library only.
